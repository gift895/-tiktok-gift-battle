ЗАПУСК С ТЕЛЕФОНА

Важное: iPhone не может сам постоянно запускать Node.js-сервер из ZIP.
Для автоматического получения подарков TikTok нужен сервер, который работает 24/7.
Поэтому один раз размести этот проект в облачном Node.js-хостинге (например, Render).

1. Создай репозиторий на GitHub и загрузи содержимое папки проекта.
2. В Render создай Web Service из этого репозитория.
3. Build Command: npm install
4. Start Command: npm start
5. Получишь HTTPS-ссылку.
6. Открой её на iPhone.
7. Открой /control.html, введи свой TikTok username и нажми «Подключить LIVE».
8. Вернись на главную страницу игры.
9. В TikTok LIVE используй трансляцию экрана, если эта функция доступна твоему аккаунту.

В проекте уже есть render.yaml.

ВАЖНО:
Официальные TikTok Webhooks не дают универсального публичного события для каждого подарка TikTok LIVE.
Поэтому автоматический счёт использует tiktok-live-connector. Это сторонний способ подключения к LIVE и он может перестать работать, если TikTok изменит внутренний протокол.
